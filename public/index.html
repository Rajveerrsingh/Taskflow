How this app is built

TaskFlow is a small issue tracker. The page never reads the database. Every change goes through /api/tasks.

  • Express routes call a controller, then a service, then a repository.
  • Zod checks the body first and returns a field error the form can show.
  • One error handler shapes validation, not found, and unexpected failures.
  • MongoDB is used when MONGODB_URI is set. Otherwise the same repository contract runs in memory.
  • There is no login. The router is the one place a session check would go.

The nine opening tasks are seed data for a bookstore inventory queue. They load only when the store is empty.
